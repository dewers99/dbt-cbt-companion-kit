# Skills Companion Kit

A portable, faith-first AI companion for practicing **DBT and CBT skills**,
steadying emotional **spirals**, and walking in faith between therapy sessions.
Built for people working through borderline personality disorder traits and
related struggles — generalized anxiety, panic, social anxiety, depression,
OCD, PTSD, eating disorders, substance use, insomnia, ADHD, and the effects of
childhood trauma or abuse. It also adapts its boundaries for bipolar disorder
and psychosis, where skills coaching has hard limits.

**This kit is educational and supportive. It is not therapy, not a diagnosis,
and not a crisis service.** It works best alongside a real therapist and/or DBT
skills group — and it will tell the user so, often.

No personal or identifying information about any individual is contained in
these files. They are designed to be shared.

## What's inside

| File | Purpose |
|---|---|
| `AGENT.md` | The companion's persona: role, tone, faith-first stance, boundaries, escalation protocol, memory rules |
| `skills/dbt-skills-coach/SKILL.md` | The full DBT skills library with plain-language coaching scripts (mindfulness, distress tolerance, emotion regulation, interpersonal effectiveness) |
| `skills/cbt-truth-steering/SKILL.md` | CBT tools for untangling emotion-backed thinking: thought records, distortion spotting, decatastrophizing, Scripture-anchored truth |
| `skills/spiral-support/SKILL.md` | The in-the-moment spiral protocol: validate → ground → separate facts from story → truth-check → pick one skill → pray → plan |
| `skills/intake-and-adaptation/SKILL.md` | First-conversation intake flow, adapting to the user's actual therapy program, and helping find a therapist or skills group |
| `skills/progress-logging/SKILL.md` | Notes and progress-log conventions: session notes, skills practice log, spiral log |
| `templates/` | Blank templates for `user-profile.md`, `session-notes.md`, `skills-practice-log.md`, `spiral-log.md` |

## Installation

Step-by-step setup instructions for Muse, ChatGPT, Claude, Microsoft Copilot,
Google Gemini, Cursor, and any other AI tool: see **[INSTALL.md](INSTALL.md)**.

**Quick version** — just send your AI agent this message:

> Install this companion kit and start intake with me:
> https://github.com/dewers99/dbt-cbt-companion-kit

Muse and similarly capable agents fetch the kit straight from the public repo —
no downloads, no uploads, no git needed. (This is why the repo is public.)

**Option 2 — download the files yourself:** on the repo page, use the green
**Code** button → **Download ZIP**, unzip it, and attach the files to your AI
chat. (Git users: `git clone https://github.com/dewers99/dbt-cbt-companion-kit.git`.)

**Option 3 — from a shared ZIP:** if someone sent you `dbt-companion-kit.zip`
directly, unzip it and attach the files to your AI chat.

## Quick start

1. Give the `AGENT.md` persona and the `skills/` folder to your AI tool (see
   "Portability" below).
2. Start a conversation. The companion runs **intake** first: name, faith
   posture, therapist/program status, current skills, support people, and how
   direct it may be.
3. It creates `companion-logs/` with the user's private profile and logs, and
   adapts from there — practicing *their* program's skills, in *their* words.

## Portability

- **Muse / Claude:** use `AGENT.md` as a custom persona/project instructions and
  add each `skills/*/SKILL.md` as a skill.
- **Other AI tools (Copilot, Cursor, ChatGPT, etc.):** `AGENT.md` works as a
  system/persona prompt; each `SKILL.md` is a standalone instruction file in the
  portable skill format (name, description, when-to-use, instructions).
- **Sharing:** the whole kit is share-ready. The shipped files contain no names,
  contacts, or personal details — those live only in the user's own
  `companion-logs/`, which is never shared.

## The core idea

Two truths at once (the DBT dialectic):

1. **The feeling is always valid.** It is real and it makes sense.
2. **The feeling is not always factual.** Emotions can tangle the mind into
   believing things that aren't true — especially doomcasting, forecasting the
   worst as if it were certain.

The companion validates first, then gently steers toward the actual truth — with
skills from DBT and CBT, and with prayer and Scripture for those who share the
Christian faith. God first, always.

## Crisis resources (US)

- **Call or text 988** — Suicide and Crisis Lifeline, 24/7
- **Text 741741** — Crisis Text Line, 24/7
- **911** — imminent danger
- Find a therapist: Psychology Today's therapist finder, SAMHSA's treatment
  locator at findtreatment.gov, or the SAMHSA National Helpline 1-800-662-4357

## A note on the research

The skills in this kit are drawn from the clinical literature on DBT (Linehan),
CBT (Beck), BPD, anxiety disorders, panic, OCD, depression, PTSD, eating
disorders, substance use, insomnia, ADHD, and bipolar disorder — including
where the evidence says a lay companion must step back (mania, psychosis,
exposure work, medical risk).
Reference notes with sources are kept separately by the kit's author and are not
part of the shipped files. Nothing here replaces professional treatment — if the
user doesn't have a therapist, the intake skill helps them find one.
